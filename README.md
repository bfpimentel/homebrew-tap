# bfpimentel's custom Homebrew tap

This tap provides casks for the following apps:

- [tinycast](https://github.com/bfpimentel/tinycast): own fork with modified code for Aerospace widgets.
    - Will be deprecated in favor of [halo](https://github.com/bfpimentel/halo).

And formulae for:

- [halo](https://github.com/bfpimentel/halo): desktop widgets for macOS, written in TSX.
